Status: finite Octave SVD rank audit only.  This is not a low-rank theorem,
volatile-rim theorem, selected-fixture classifier theorem, pointwise
character-sum estimate, or Goldbach proof.

## Mechanism

The adverse-absorption ladder leaves a full six-versus-two channel balance at
the tight row `1222142`.  This receipt asks whether that balance is only the
shadow of a lower-rank linear-algebra structure.

Each selected row is oriented so positive channel mass helps the row's actual
classification.  Octave then computes the SVD of the resulting `10 by 8`
oriented volatile-channel matrix.  For each truncated rank, the audit
reconstructs the channel matrix and tests whether:

```text
oriented base margin + reconstructed oriented channel sum > 0
```

for every selected row.

## Results

Octave `11.3.0` was used for the SVD and truncated-rank replay.

Rank `4` captures about `0.9315947381` of the oriented volatile-channel matrix
energy, but it still leaves five selected rows with nonpositive reconstructed
oriented margin.  Rank `5` is the first truncation preserving all selected
row classifications, with minimum reconstructed oriented margin about
`0.0055715827`.

## Interpretation

This demotes the attractive rank-`<=4` shortcut on the current selected
fixture.  The q286 loop is still tightening, but the six-versus-two stress
balance is not replaced by a very-low-rank SVD explanation here.

Low-rank linear algebra remains a useful diagnostic.  It is not yet a proof
engine.  The live theorem target remains the critical adverse-pair absorption
balance from actual binary-prime residue weights, or a stronger signed
aggregate arithmetic-placement theorem.
